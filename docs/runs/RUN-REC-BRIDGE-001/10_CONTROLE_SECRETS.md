# RUN-REC-BRIDGE-001 — Contrôle de secrets avant versement

Les exports de workflows inclus dans ce package ont été contrôlés avant préparation du versement Git.

Les références n8n visibles sont des **identifiants et noms de credentials**, par exemple :
- `BAW OS — Mistral`
- `BAW OS — PostgreSQL`

Aucune valeur de mot de passe, clé API ou secret de credential n'est incluse dans le package.

Les dumps de bases, exports globaux et coffres de secrets sont exclus du versement Git.
