# BAW OS — Déploiement

Ce dépôt contient la recette reproductible de déploiement de BAW OS.

## Contenu prévu

- fichiers Docker Compose ;
- configurations versionnables ;
- scripts PowerShell ;
- documentation d'installation ;
- procédures de sauvegarde et de restauration ;
- contrôles de fonctionnement.

## Branches

- `main` : déploiement validé
- `develop` : évolution de l'infrastructure

## Données exclues

Les volumes Docker, bases de données, sauvegardes et secrets ne sont jamais
stockés dans ce dépôt.
